## 🎓 KEY TAKEAWAYS

### The Problem
```python
# ❌ BEFORE: Sets have undefined order
unique_ids = {"3", "1", "2"}
# Output varies: "3, 1, 2" or "1, 2, 3" or "2, 3, 1"
# FLAKY! Tests fail randomly
```

### The Solution
```python
# ✅ AFTER: Lists are ordered
unique_ids = ["1", "2", "3"]  # sorted
# Output always: "1, 2, 3"
# DETERMINISTIC! Tests never fail
```
